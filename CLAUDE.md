# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

A multi-platform **skills marketplace**: a single source of truth for personal
agent skills, published so they install on Claude Code, Codex, and Antigravity.
The marketplace name is `gridin-skills`.

## Core invariant

**`SKILL.md` files are the only hand-authored manifest input.** Every JSON file
under `.claude-plugin/`, `.codex-plugin/`, and `.agents/plugins/` is generated by
`scripts/generate-manifests.mjs`. Never hand-edit generated JSON — change the
`SKILL.md` (or a plugin's `plugin.meta.json`) and re-run the generator.

## Commands

```bash
python scripts/generate_manifests.py          # regenerate all manifests (idempotent)
python scripts/generate_manifests.py --check   # CI: fail if manifests are stale, write nothing
scripts/sync.sh        [--copy] [--clean]     # link/copy skills into each tool's skills dir
./scripts/sync.ps1     [-Copy] [-Clean]       # same, PowerShell (Windows)
claude plugin validate .                       # validate the Claude marketplace manifest
```

Run `generate_manifests.py` after adding, renaming, or removing any skill, and
commit the regenerated JSON alongside the `SKILL.md` change. Requires Python 3
(stdlib only, no dependencies).

## Architecture

- **Skill** = unit of authoring: `plugins/<plugin>/skills/<skill>/SKILL.md`,
  front matter `name` (kebab-case, matches its dir, globally unique) +
  `description`.
- **Plugin** = unit of installation: a directory under `plugins/`. It contains
  one skill (metadata derived from that skill) or several skills (requires
  `plugin.meta.json` with `name`/`description`/`version`). Plugin name must match
  its directory and be globally unique.
- `version` defaults to `0.1.0` and is never bumped automatically. To version a
  plugin, add `plugin.meta.json` with a `version`. For a single-skill plugin
  every other field is optional there — `name`/`description` still fall back to
  the skill, so don't restate the description and let it drift.
- The generator scans `plugins/*/skills/*/SKILL.md` and writes, per platform:
  - Claude: `plugins/<p>/.claude-plugin/plugin.json` + root
    `.claude-plugin/marketplace.json`.
  - Codex: `plugins/<p>/.codex-plugin/plugin.json` + `.agents/plugins/marketplace.json`.
  Both catalogs point at the same `plugins/<p>` directories; skill content is
  never duplicated.
- `scripts/sync.*` is skill-granular (it links each `skills/<skill>` into the
  tools' flat personal skills dirs) and is the supported install path for
  Antigravity.

## Validation rules enforced by the generator

Missing `name`/`description` front matter, non-kebab-case names, a skill `name`
that doesn't match its directory, duplicate skill names, and a multi-skill plugin
without `plugin.meta.json` all fail the generator. Keep skill and plugin names
globally unique because `sync` places skills into flat per-tool directories.

## Unverified

Whether Antigravity's native `/plugin marketplace add` reads the Claude
`.claude-plugin/marketplace.json` is not yet confirmed. Until it is, treat the
sync script as Antigravity's supported path. The Codex catalog
(`.agents/plugins/marketplace.json`) shape is a best effort against documented
fields; verify against a live `codex plugin marketplace add` before relying on it.
